# DrinkFlowKDS.com

Static product landing page for DrinkFlow KDS.

## Vercel Setup

- Framework Preset: Other
- Root Directory: `drinkflow-site`
- Build Command: leave blank
- Output Directory: leave blank
- Install Command: leave blank

## Domain

Add `DrinkFlowKDS.com` and `www.DrinkFlowKDS.com` to this Vercel project, then update GoDaddy DNS with the records Vercel provides.
